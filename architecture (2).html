LangGraph Agentic Workflow

Durable, resumable graph backed by SQLite checkpoints. Streams SSE events per node. Pauses at Human Gate until the user approves or cancels.

NodeActionOn Failure
DiscoveryCalls collect_vcenter_inventory(); saves {uuid}.json to disk; returns VM count summary→ END (phase=failed)
PlanningCalls generate_and_save_plan(); dispatches to selected LLM; post-processes and saves {uuid}_plan.json→ END (phase=failed)
Human Gateinterrupt() — pauses the graph; resumes with MigrationRequest JSON or cancel:truecancel → END (phase=cancelled)
MigrationCreates migration_parent task; spins daemon thread calling migrate(); returns task_id→ END (phase=failed)
State is persisted to backend/data/langgraph_checkpoints.sqlite. Resume any workflow later via POST /api/v1/workflow/{thread_id}/resume or stream via POST /api/v1/workflow/{thread_id}/resume-stream.

Per-VM Migration Pipeline

Each VM is migrated in parallel (ThreadPoolExecutor, max 5 workers). Each VM has its own child task. Parent progress = average of all child percentages.
